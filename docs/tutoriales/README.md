# Videotutoriales de ArqNova

Las videoguías incluidas en esta carpeta resumen los flujos que deben demostrarse durante el examen. Se reproducen directamente desde GitHub o después de clonar el repositorio.

## 1. Editor e interoperabilidad XMI

[Ver videotutorial](videos/01-editor-xmi.mp4)

Flujo cubierto:

1. Abrir un proyecto UML.
2. Editar clases y relaciones en el lienzo.
3. Seleccionar **Importar XMI** y validar la vista previa.
4. Incorporar el modelo como elementos editables.
5. Seleccionar **Exportar XMI** y descargar el archivo compatible.

## 2. Generación de backend y Postman

[Ver videotutorial](videos/02-generacion-backend.mp4)

Flujo cubierto:

1. Validar el modelo UML actual.
2. Configurar nombre y paquete base.
3. Generar el proyecto Spring Boot.
4. Revisar entidades, repositorios, servicios y controladores.
5. Descargar el ZIP y la colección Postman.

## 3. Aplicación Android, asistente y modo offline

[Ver videotutorial](videos/03-mobile-offline.mp4)

Flujo cubierto:

1. Abrir ArqNova Mobile.
2. Interpretar un comando por texto o voz.
3. Ejecutar una operación contra el backend.
4. Guardar una operación cuando no existe conexión.
5. Sincronizarla al recuperar Internet.

## Guion corto para demostración colaborativa en vivo

1. Abrir dos navegadores con usuarios distintos.
2. El anfitrión comparte el enlace de sesión.
3. El colaborador ingresa y aparece en el panel.
4. Mover ambos cursores y comprobar nombre y color.
5. Crear o editar una clase y comprobar el cambio remoto.
6. Mostrar el lock y la actividad registrada.

La colaboración se recomienda demostrar en vivo porque necesita dos sesiones autenticadas simultáneas; el videotutorial complementa, pero no sustituye, esta prueba.
